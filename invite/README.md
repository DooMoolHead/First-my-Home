# 밍짜네 집들이 초대장

- `a.html` 편지지 · `b.html` 참석 계약서 · `c.html` 도어락 + 평면도
- 내용 수정: `config.js` 하나만 고치면 세 초안 모두 바뀜
- 사진: `photos/` 폴더에 넣고 `config.js`의 `photos.hero`, `photos.gallery`에 파일명 적기

## 참석/투표 저장 연결 (구글 시트, 무료, 5분)

`config.js`의 `endpoint`가 비어 있으면 미리보기 모드라서 응답이 각자 폰에만 저장돼요. 친구들 응답을 한곳에 모으려면:

1. 구글 시트를 새로 만들어요 (이름은 아무거나, 예: 밍짜네 집들이 응답).
2. 메뉴에서 **확장 프로그램 → Apps Script**를 열어요.
3. 기본 코드를 지우고 `apps-script.gs` 내용을 통째로 붙여넣은 뒤 저장해요.
4. 오른쪽 위 **배포 → 새 배포**를 누르고 아래처럼 설정해요.
   - 유형: 웹 앱
   - 실행 계정: 나
   - 액세스 권한: **모든 사용자**
5. 권한 승인 화면이 나오면 "고급 → 안전하지 않은 페이지로 이동"을 눌러요. 내가 만든 스크립트라 괜찮아요.
6. 배포가 끝나면 나오는 `https://script.google.com/macros/s/.../exec` 주소를 `config.js`의 `endpoint`에 넣어요.

응답은 시트에 한 줄씩 쌓이고, 같은 이름으로 다시 내면 그 줄이 수정돼요. 차량번호 전체는 시트에서만 볼 수 있고, 초대장 화면에는 뒤 4자리만 보여요.

## 날짜 확정

투표가 끝나면 `config.js`의 `confirmedDate: '2027-03-13'`처럼 확정 날짜를 넣어요. 그러면 투표가 닫히고 확정된 날짜로 표시돼요.
